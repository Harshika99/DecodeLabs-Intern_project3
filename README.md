# ATM Interface Project

This is a simple Java-based ATM Interface project developed using Object-Oriented Programming (OOP) concepts. The project simulates basic ATM operations such as deposit, withdrawal, and balance checking through a menu-driven console application.

** Features**

* Deposit money
* Withdraw money
* Check account balance
* Input validation for invalid amounts and insufficient balance
* Menu-driven user interaction

**Technologies Used**

* Java
* OOP Concepts (Classes, Objects, Encapsulation)
* Scanner Class for user input

** Concepts Covered**

* Classes and Objects
* Constructors
* Methods
* Encapsulation
* Conditional Statements
* Loops
* Switch Case

This project helped in understanding how real-world banking operations can be implemented using Java programming and object-oriented principles.
